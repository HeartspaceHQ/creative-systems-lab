# Provenance of this repository

This code was written new in this repository, with no copied history. It was designed after
reviewing a private local workspace of image and video generation experiments, brand templates
and review tooling. Three ideas carried over as concepts, and were reimplemented cleanly:

- model swapping and licence selection (a measured model comparison in the source workspace that
  led to a registry with explicit exclusion reasons),
- recipe plus pinned model revision as the unit of reproducibility (the source workspace
  re-ran seeds to check determinism),
- an independent review step with measured checks rather than opinion.

No client material, customer brand assets or private-project paths are included. The example
brand is invented. Reference and result images in `examples/` were generated by this system.
